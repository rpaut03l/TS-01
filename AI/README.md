## 🍼 How to Use This Repo (The 5-Year-Old Way!)

1. **Start from Topic 01** and go in order — each topic builds on the previous one
2. **Read the "Explain Like I'm 5" section** first in every README
3. **Look at the pictures and diagrams** — they tell the story better than words
4. **Try the examples** — change numbers, break things, see what happens
5. **Check the "Key Takeaways"** before moving to the next topic
6. **Use the "Exam Tips"** section when preparing for quizzes

> 💡 **Pro Tip**: Each README has a difficulty meter: 🟢 Easy → 🟡 Medium → 🔴 Hard
