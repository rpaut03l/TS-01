## 📋 FORMULA CHEAT SHEET

> 🔗 See derivations → [Theory Guide](./Probability_BootCamp_THEORY.md) | See worked examples → [Practice Guide](./Probability_BootCamp_PRACTICE.md)

```
╔══════════════════════════════════════════════════════════════════════════════╗
║  COUNTING:  P(n,r)=n!/(n-r)!   C(n,k)=n!/[k!(n-k)!]                          ║
║  BASIC:     P(A)=favorable/total   P(not A)=1−P(A)                           ║
║  ADD:       P(A∪B)=P(A)+P(B)−P(A∩B)                                          ║
║  MULTIPLY:  P(A∩B)=P(A)·P(B|A)    [if independent: =P(A)·P(B)]               ║
║  TOTAL:     P(B)=ΣP(B|Aᵢ)P(Aᵢ)                                               ║
║  BAYES:     P(A|B)=P(B|A)·P(A)/P(B)                                          ║
╠══════════════════════════════════════════════════════════════════════════════╣
║  DISTRIBUTIONS                                                               ║
║  Bernoulli:  P(X=1)=p, P(X=0)=1−p        E=p, Var=p(1−p)                     ║
║  Binomial:   P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ      E=np, Var=np(1−p)                  ║
║  Poisson:    P(X=k)=e⁻λ·λᵏ/k!              E=λ, Var=λ                        ║
║  Geometric:  P(X=k)=(1−p)ᵏ⁻¹·p              E=1/p, Var=(1−p)/p²              ║
║  Normal:     f(x)=(1/σ√2π)e^(−(x−μ)²/2σ²)  E=μ, Var=σ²                       ║
║  Exponential:f(x)=λe⁻λˣ  (x≥0)             E=1/λ, Var=1/λ²                   ║
║  Gamma:      f(x)=[λᵅ/Γ(α)]x^(α−1)e⁻λˣ     E=α/λ, Var=α/λ²                   ║
║  Chi-sq(k):  Gamma(k/2, 1/2)                E=k, Var=2k                      ║
╠══════════════════════════════════════════════════════════════════════════════╣
║  SUMMARY STATS                                                               ║
║  E[X]=Σx·P(x) or ∫x·f(x)dx     E[aX+b]=aE[X]+b                               ║
║  Var(X)=E[X²]−(E[X])²           Var(aX+b)=a²Var(X)                           ║
║  σ=√Var(X)                       Cov(X,Y)=E[XY]−E[X]E[Y]                     ║
║  ρ=Cov(X,Y)/(σₓ·σᵧ)            −1≤ρ≤1                                        ║
╠══════════════════════════════════════════════════════════════════════════════╣
║  BIG THEOREMS                                                                ║
║  Markov:     P(X≥a) ≤ E[X]/a                                                 ║
║  Chebyshev:  P(|X−μ|≥kσ) ≤ 1/k²                                              ║
║  LLN:        X̄ₙ → μ as n→∞                                                   ║
║  CLT:        (X̄ₙ−μ)/(σ/√n) → N(0,1) as n→∞                                   ║
╚══════════════════════════════════════════════════════════════════════════════╝
```

  ┌─────────────────────────────────────────────────────────────────────┐
  │                     DISCRETE DISTRIBUTIONS                          │

  │       │                                    │                        │

  │       │                                    │                        │

  │   until 1st                          Poisson(λ)                     │
  │   success]                                                          │
  │       │                                                             │

  │                    CONTINUOUS DISTRIBUTIONS                         │

  │                                    │                                │
  │                             [standardize]                           │
  │                                    │                                │
