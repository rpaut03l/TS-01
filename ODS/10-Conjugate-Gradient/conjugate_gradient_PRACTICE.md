## P1: CG for 2D Quadratic (From Lectures 8-9)

**Q:** f(x) = (x₁-3)² + 2(x₂-2)², x₀ = (1,1). Solve by CG.

```
Q = [[2,0],[0,4]], b = [-6,-8]ᵀ, c = 17.
∇f = Qx + b = [2x₁-6, 4x₂-8]

Step 0:
  g₀ = Q[1,1]ᵀ + b = [2-6, 4-8] = [-4, -4]
  p₀ = -g₀ = [4, 4]

  α₀ = -(g₀ᵀp₀)/(p₀ᵀQp₀) = -((-4)(4)+(-4)(4))/([4,4]ᵀ[[2,0],[0,4]][4,4])
     = -(-32)/([4,4]·[8,16]) = 32/(32+64) = 32/96 = 1/3

  x₁ = [1,1] + (1/3)[4,4] = [7/3, 7/3]
  g₁ = Q[7/3,7/3]ᵀ + b = [14/3-6, 28/3-8] = [-4/3, 4/3]

Step 1:
  β₁ = (g₁ᵀg₁)/(g₀ᵀg₀) = (16/9+16/9)/(16+16) = (32/9)/32 = 1/9
  p₁ = -g₁ + β₁p₀ = [4/3, -4/3] + (1/9)[4,4] = [4/3+4/9, -4/3+4/9]
     = [16/9, -8/9]

  α₁ = -(g₁ᵀp₁)/(p₁ᵀQp₁)
     = -((-4/3)(16/9)+(4/3)(-8/9)) / ([16/9,-8/9]·Q·[16/9,-8/9])
     = -((-64/27)+(-32/27)) / ([16/9,-8/9]·[32/9,-32/9])
     = -(-96/27) / (512/81 + 256/81)
     = (96/27) / (768/81)
     = (96/27)·(81/768) = (96·3)/768 = 288/768 = 3/8

  x₂ = [7/3, 7/3] + (3/8)[16/9, -8/9] = [7/3 + 2/3, 7/3 - 1/3] = [3, 2]

Verify: ∇f(3,2) = [2(3)-6, 4(2)-8] = [0, 0] ✓

Solved in exactly 2 steps (n=2 dimensions)! ✓
```

---

## P2: Verify Conjugacy

**Q:** From P1, verify p₀ and p₁ are Q-conjugate.

```
p₀ᵀQp₁ = [4,4]·Q·[16/9,-8/9] = [4,4]·[32/9,-32/9]
        = 128/9 + (-128/9) = 0 ✓

They are Q-conjugate!
```
