## 🎯 What Is This Repository About?

Imagine you have a **messy room full of toys**. Some toys are big, some are small, some you play with every day, and some you forgot about.

**Data Structures** = The **boxes, shelves, and drawers** you use to organize your toys.
**Algorithms** = The **step-by-step instructions** you follow to clean your room, find a toy, or sort them by color.
**Techniques** = The **clever tricks** you learn (like always putting your favorite toy on top so you find it fast!).

This repo covers **everything** from sorting toys in a line to finding the fastest route on a treasure map!

## 🧭 Learning Path — Recommended Order

```
Step 1: Sorting
   ├── Insertion Sort     (the simplest sort — like sorting cards in your hand)
   └── Merge Sort         (divide and conquer — split, sort halves, merge)

Step 2: Solving Recurrences
   └── Recursion Tree Method  (draw a tree to figure out how fast your algorithm runs)

Step 3: Data Structures
   ├── BST                    (organized tree for fast searching)
   ├── Red-Black Trees        (BST that keeps itself balanced)
   ├── Augmenting Trees       (BST with extra info like "how many nodes in subtree?")
   └── Disjoint-Set Union     (grouping things into sets, merging groups)

Step 4: Graphs
   ├── Introduction           (what are graphs, BFS, DFS)
   ├── Dijkstra               (shortest path)
   ├── Network Flow           (Ford-Fulkerson method)
   └── Bipartite Matching     (optimal pairing)

Step 5: Dynamic Programming
   ├── Rod Cutting            (maximize profit by cutting smartly)
   └── LCS                    (find longest common subsequence)

Step 6: Greedy
   └── Interview Scheduling   (pick the most activities without overlap)
```

## 📝 How To Use This Repository

1. **Start from the top** — Follow the learning path in order.
2. **Read each README** — Each topic has a "5-year-old" explanation, then dives deeper.
3. **Try the examples** — Every README has step-by-step walkthroughs.
4. **Understand the pseudocode** — Code is explained line by line.
5. **Know the complexities** — Every topic lists Time and Space complexity.
6. **Practice problems** — Each topic ends with real-world examples and practice questions.
